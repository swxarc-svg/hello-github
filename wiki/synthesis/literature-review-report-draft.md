# 文獻梳理報告（第一階段）

**研究主題**：微氣候適應性城市戶外公共空間遮陽系統
**報告日期**：2026年4月9日
**說明**：本報告為第一阶段梳理成果，現已完整精讀3篇文獻。後續將擴充至20篇以上。

## 一、文獻信息表

### 文獻一

**Ghoniem, M., Fahmy, A., & Kamel, T. M. (2025).** Evaluating Urban Surface Materials: Albedo Optimization and Shading for Pedestrian Thermal Comfort in Hot-Arid Environments. *Civil Engineering and Architecture*, 13(6), 4331–4352. https://doi.org/10.13189/cea.2025.130616

| 項目 | 內容 |
|------|------|
| **研究背景** | 開羅商業步行街夏季熱應激嚴重；「冷鋪裝」（高反射率地面材料）作為城市降溫策略被廣泛推廣，但其對行人熱舒適的實際效果尚無系統性評估；遮陽與材料選擇的交互作用研究不足 |
| **研究創新點** | 不同於以往單獨研究鋪裝材料或遮陽的傳統方法，本研究同時隔離地表反射率與遮陽兩個變量，揭示其交互作用——高反射率鋪裝在無遮陽條件下反而因短波輻射反射而顯著抬升MRT，惡化行人熱舒適；並建立並驗證ENVI-met與Ladybug雙平台協同工作流 |
| **理論意義／現實價值** | 遮陽是改善行人熱舒適的首要槓桿，地表材料選擇是次要的；冷鋪裝策略若缺乏頭頂遮陽配合，不僅效果受限，更可能使UTCI惡化至極端熱應激（>46°C）——對城市熱緩解政策制定具有直接警示意義 |
| **空間類型** | 低矮商業步行街（開羅新城，單一街道剖面） |
| **遮陽做法類型** | 模塊化圓形固定遮陽篷（白漆木結構），均勻陣列佈置，高度2.65–2.87 m，間距7.35 m |
| **評價指標** | UTCI（通用熱氣候指數）、MRT（平均輻射溫度）、Ta（氣溫）、Ts（地表溫度） |
| **研究方法** | 模擬為主、實測驗證：ENVI-met 5.7.1模擬三組反射率方案（0.12／0.20／0.30），Grasshopper/Ladybug v1.8計算MRT與UTCI；以8月15日峰值夏季現場實測數據校驗模擬結果（MRT R²=0.924；Ta R²=0.984） |
| **主要結果** | ①遮陽篷介入使UTCI降低5–6.6°C，且效果在各反射率方案下一致；②反射率0.30 vs 0.12使地表溫度降低7°C，但在無遮陽情況下MRT上升最多6°C；③無遮陽高反射率場景下UTCI可達46.9°C（極端熱應激）；④遮陽可完全中和高反射率帶來的MRT懲罰 |
| **實驗技術／儀器** | ENVI-met 5.7.1（模擬域50×50 m，水平分辨率2 m，垂直0.5 m）；Grasshopper/Ladybug Tools v1.8；現場儀器：Testo 435-2（氣溫／相對濕度）、Testo黑球溫度探頭（ISO 7726）、熱線風速儀、Extech EasyView IAQ計 |
| **局限** | 僅研究單一低矮商業街道形態；僅測量一天（8月15日）；基線模型不含植被（可能高估無遮陽MRT）；研究背景為熱乾燥氣候，不可直接移植至濕熱或颱風氣候環境 |

### 文獻二

**Hassan, M., Torky, E., & El-Mahdy, D. (2025).** Knitted Textile Canopies: A Rapid Generative Design Optimization Tool for Enhanced Shading Performance. *Nexus Network Journal*, 27, 875–904. https://doi.org/10.1007/s00004-025-00839-7

| 項目 | 內容 |
|------|------|
| **研究背景** | 城市戶外空間夏季過熱問題普遍；遮陽篷是常見應對策略，但其形態設計缺乏系統性多目標優化工具；Grasshopper生態系統中多種優化插件的適用性從未被系統比較 |
| **研究創新點** | 不依賴傳統單目標遺傳算法（Galapagos）的優化思路，首次在同一遮陽優化任務下系統比較Biomorpher、Octopus、Galapagos三款插件的效率與解質量；提出可複製的參數化遮陽幾何多目標生成工作流，並驗證Biomorpher作為快速多目標工具的優越性 |
| **理論意義／現實價值** | 為參數化遮陽設計提供明確工具選型依據：Biomorpher在5分鐘內生成313個方案並同時達成4項設計目標，效率是Galapagos的2倍以上；雙曲面鞍形幾何可在多時段同時實現最大遮影覆蓋 |
| **空間類型** | 開放式校園廣場（埃及英國大學BUE校區），基準面10×5 m |
| **遮陽做法類型** | 雙曲面鞍形針織紡織膜篷（GFRP彎曲杆＋鋼索網＋PTFE塗層CNC針織膜）；固定安裝，膜結構跨度能力3–200 m |
| **評價指標** | 遮影覆蓋率（%）作為熱舒適代理指標（非完整UTCI計算；風速、濕度、MRT均未納入） |
| **研究方法** | 純模擬：Grasshopper/Rhino參數化建模（33個UV控制滑塊），Ladybug陰影投射（開羅EPW氣象數據，8月21日09:00、12:00、14:00）；三款插件運行對比（Galapagos、Octopus各15分鐘，Biomorpher 5分鐘5代）；結果導出Excel篩選前10% |
| **主要結果** | Biomorpher最優方案No.301：三時段遮影率分別為98.36%／95.80%／94.73%，占地面積27.05 m²；Biomorpher是唯一同時達成4項目標的工具；鞍形雙曲面幾何為最優形態；14:00遮影率可超過100%（太陽角度低，陰影超出篷邊界） |
| **實驗技術／儀器** | Rhinoceros 3D；Grasshopper（Biomorpher、Octopus [SPEA-2算法]、Galapagos [模擬退火]）；Ladybug太陽輻射與陰影分析；運行硬件：12 GB RAM / Intel Core i5 8代（算力限制已說明） |
| **局限** | 未進行結構有限元分析（FEA）或風荷載評估（作者明確承認，為直接研究缺口）；遮影率不等於熱舒適；研究背景為熱乾燥氣候；篷體無可動或收納機制，不適用於颱風應對場景 |

### 文獻三

**Lyu, R., Zhao, J., & Chen, G. (2026).** From Algorithmic Intent to Accountable Assembly: A Computational Delivery Framework for Digital Architecture. *E3S Web of Conferences*, 683, 01012. https://doi.org/10.1051/e3sconf/202668301012

| 項目 | 內容 |
|------|------|
| **研究背景** | 生成式設計工作流在從設計意圖到建造交付過程中頻繁在製造邊界、認證程序和生命週期運維處失效；計算建築領域缺乏從算法意圖到可問責組裝的系統性交付框架 |
| **研究創新點** | 不同於以往聚焦生成工具本身（形態找形、多目標優化），本研究提出**計算交付框架（CDF）**，系統梳理「意圖編碼→物質化意圖→驗證意圖」三階段的內在邏輯與失效機制；首次將「可保險性（insurability）」引入生成設計的評價維度 |
| **理論意義／現實價值** | 將數字建築的評價標準從新奇性轉向可認證性、可維護性與可保險性；為設計師提供識別工作流斷裂點的系統性詞彙；對數字化設計實踐轉化為可建造、可驗收成果具有方法論指導意義 |
| **空間類型** | 以建築外圍護系統（立面、屋面）為主要測試床，非直接針對戶外公共空間 |
| **遮陽做法類型** | 綜述性涵蓋：CNC減材製造（木板）、增材製造（3D混凝土打印、WAAM金屬絲電弧增材）、機器人成型與混合工藝；案例含HiLo自適應太陽能立面、Media-TIC ETFE氣枕等 |
| **評價指標** | DA（採光自主率）、EUI（單位面積能源使用強度）、TRL（技術成熟度等級）——非行人熱舒適指標 |
| **研究方法** | 概念性評述（非實證研究）；綜合既有文獻與典型案例（BUGA木亭、Urbach Tower、HiLo ASF、Media-TIC ETFE、livMatS仿生殼） |
| **主要結果** | ①提出CDF三階段框架；②識別三大系統性張力：幾何自由度vs製造可行性、推測性原型vs有保固的交付、模擬樂觀主義vs制度問責；③MOO工具批判：Pareto最優解集掩蓋文化與制度偏見，無法捕捉氛圍、儀式等質性價值；④未來研究議程：將可保險性嵌入生成工作流，運用數字孿生進行法規協商 |
| **實驗技術／儀器** | 無實驗（概念論文）；綜述提及工具：Kangaroo（物理仿真找形）、Octopus、Wallacei（多目標優化） |
| **局限** | 會議論文篇幅有限，論述深度受約束；CDF框架本身未經實證驗證；無量化基準；不直接涉及遮陽系統、戶外熱舒適或颱風韌性 |
